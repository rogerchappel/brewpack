# Security Policy

## Supported Versions

This project is pre-1.0 and does not currently promise long-term support windows.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1.0 | No |

## Reporting a Vulnerability

Please do not report vulnerabilities in public issues or pull requests.

Use GitHub Security Advisories for private reporting when available for `rogerchappel/brewpack`. If private reporting is unavailable, open a minimal public issue asking for a private contact path without including exploit details.

## Scope

In scope:

- The `brewpack` CLI and library code in this repository
- Generated project guidance that could cause insecure defaults
- CI and release automation maintained here

Out of scope:

- Vulnerabilities in downstream tap repositories after maintainers modify generated files
- Third-party services or package registries
- General support questions

## Response expectations

Best effort only. No SLA is promised.
